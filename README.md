## 🔥 Featured Project

### 🏆 Azure Retail Behavior Lakehouse

End-to-end modern data engineering project simulating an Azure Lakehouse architecture with **PySpark + Delta Lake + Power BI**.

Built with Medallion Architecture:

- Bronze Layer → Raw ingestion  
- Silver Layer → Cleaned & standardized data  
- Gold Layer → Business KPIs & analytics marts  

Includes interactive dashboards for:

📊 Executive Overview  
🛒 Product & Category Analytics  
🧪 Data Quality Monitoring  

**Business Impact Example:**

- Metadata Coverage: **50% → 90%**
- Product Mapping Rate: **43% → 78%**
- Conversion Funnel Analysis
- Cart Abandonment Insights
